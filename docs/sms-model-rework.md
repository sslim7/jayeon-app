# 문자 모델 재설계 — 캠페인을 없애고 건당 레코드로 (2026-09-28 메모)

**상태: 착수 전.** 요구사항부터 다시 정리해야 하는 작업이라, 시작하기 전에 이 문서를 먼저 읽고
아래 「먼저 답해야 할 것」을 채운 뒤 들어간다.

## 사용자가 말한 것 (원문)

> 캠페인은 필요없어, 문자보내기에서 수시로 예약에 줏어담는데 왜 캠페인이 의미있어
> 캠페인단위는 존재할 필요가없어
> 그러니까 캠페인개념 필요없다고 **그냥 트랜젝션단위 개별개별**이야
> **묶는건 기능으로** 이사람들중 5명 보내자 체크 이런거야

즉 **한 사람 한 건이 발송 단위**이고, 「묶음」은 화면에서 체크하는 행위일 뿐이다.

## 왜 이 말이 맞나 — 어긋남이 실제로 만든 사고들

2026-09-27~28 하루에 아래가 전부 같은 뿌리에서 나왔다.

| 증상 | 뿌리 |
|---|---|
| 7명 예약에서 1명 보냈더니 **나머지 6명이 예약함에서 사라짐** | 예약 목록이 사람이 아니라 **캠페인 상태**(`status === 'READY'`)로 걸렀다. 한 명만 보내도 서버가 캠페인을 `SENDING` 으로 옮긴다 |
| 예약에서 **한 명만 빼기가 불가능** | 서버에 그런 API 가 없다. 그래서 `app/sms/reserved.tsx` 의 `cancelSelected` 가 **남는 사람으로 예약을 새로 만들고 기존 것을 취소**하는 우회를 쓴다 — 모델이 안 맞아 코드가 돌아가는 자리다 |
| 고른 사람이 두 예약에 걸치면 **발송 버튼이 아무 설명 없이 꺼짐** | `reserved.tsx` 의 `single = groups.length === 1 ? … : null`. 캠페인 경계가 그대로 UI 제약이 됐다 |
| 「미발송이 누구인지」를 이력에서 못 찾음 → 서버가 READY 도 내려보내게 고쳤더니, 이번엔 **아직 차례도 안 온 사람이 발송 이력에 섞임** | 「예약」과 「보내다 만 것」이 한 모델에 얹혀 있어 어느 쪽 기준으로도 정답이 없었다 |

## 🔴 캠페인이 실제로 해 주고 있는 일 — 없애면 대신할 것이 필요하다

**이것을 대신할 설계 없이 지우면 안 된다.**

1. **보낸 그 순간의 본문·첨부 스냅샷.** 수신자마다 `message`·`attachments` 를 들고 있어, 템플릿을
   나중에 고쳐도 이력이 「그때 보낸 것」을 그대로 말한다.
2. **발송 잠금(claim).** `PATCH /sms/campaigns/{id}/recipients/{rid}` 가 `status: READY → SENDING`
   을 원자적으로 뒤집고, 서버가 **캠페인에 SENDING 이 하나라도 있으면 다음 claim 을 거절**한다
   (`internal/sms/model.go` 의 `apply`). 같은 사람에게 두 번 나가는 것을 막는 유일한 장치다.
3. **시도 기록(attempts).** 「왜 안 갔지」를 가릴 근거. 재시도가 지난 실패를 덮지 않는다.
4. **멱등성.** `attemptId` 로 같은 결과가 두 번 기록되지 않는다.

건당 레코드로 가면 1·3·4 는 레코드가 그대로 들고 있으면 되지만, **2 는 다시 설계해야 한다** —
캠페인이라는 울타리가 사라지면 「지금 이 사람에게 보내는 중」을 무엇이 보장하는가.

## 먼저 답해야 할 것

- **예약이란 무엇인가.** (사람 + 템플릿)인가, (사람 + 그때 고정된 본문·첨부)인가? 템플릿을
  고치면 이미 예약된 건의 내용이 바뀌어야 하나?
- **한 건의 발송 레코드가 들고 있어야 하는 것**은 무엇인가. 위 1~4 를 어떻게 나눠 담을 것인가.
- **두 번 발송 방지**를 무엇으로 할 것인가. 레코드 단위 잠금이면 동시성 경계는 어디인가.
- **기존 데이터 이전.** 지금 쌓인 캠페인·수신자·시도·외부 발송 기록을 어떻게 옮기나. 이력이
  끊기면 안 된다.
- **발송 이력의 묶음 기준.** 지금은 (일자, 템플릿)이다. 캠페인이 없어지면 그대로 두면 되나?
- **외부 발송 등록**(`source: 'EXTERNAL'`, 캠페인 없이 기록만 남기는 것)은 새 모델에서 어떻게
  자연스럽게 들어가나. ⚠️ 지금은 캠페인이 없어서 여러 자리에서 예외가 되고 있다.
